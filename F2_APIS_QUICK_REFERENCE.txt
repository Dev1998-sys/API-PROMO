                      TEST EXECUTION COMMANDS
================================================================================

Run all F2 tests:
  mvn test -Dtest=F2_*

Run single F2 test class:
  mvn test -Dtest=F2CoreBundleAPI

Run F2 tests with Allure report:
  mvn clean test -Dtest=F2_* allure:report

  mvn test -Dtest=F2Resolve*

  mvn test -Dtest=F2Scope*

Run tests from TestNG suite:
  java -cp target/classes:target/test-classes org.testng.TestNG testng.xml
